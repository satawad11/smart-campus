## ฟีเจอร์ใหม่
- **จัดการข้อมูลบุคลากร**: เพิ่มหน้ารายชื่อ ค้นหา กรองสถานะการทำงาน ดูประวัติ แก้ไขข้อมูล และนำเข้าบุคลากรจาก CSV
- **จัดการสถานที่และโซน**: เพิ่ม แก้ไข และปิดใช้งานสถานที่และโซนจากหน้าเว็บ
- **ข้อมูลการศึกษา**: เพิ่มหน้าจัดการแผนก หลักสูตร และห้องเรียน
- **บุคคลและผู้มาติดต่อ**: เพิ่มข้อมูลผู้ปกครอง บุคคลภายนอก การเยี่ยม และสถานะของบุคคล พร้อมสิทธิ์แยกตามประเภท
- **เฝ้าระวังและแจ้งเตือนแบบเรียลไทม์**: แสดงชื่อ กลุ่ม รหัส และคะแนนความคล้ายบนหน้าจอเฝ้าระวัง พร้อมแจ้งเตือนบุคคลไม่รู้จักและรายการปฏิเสธ
- **ลงทะเบียนและทดสอบใบหน้าผ่านเว็บแคม**: เลือกบุคคลจากข้อมูลนักเรียน บุคลากร หรือบุคคลประเภทอื่นที่ระบบรองรับ และบันทึกแหล่งที่มาของภาพ
- **รายงานการเข้าออก**: เพิ่มรายงานเวลาเข้าออกและส่งออก CSV

## ปรับปรุง
- ใช้ UUID ใน URL สำหรับแก้ไขสถานที่และโซน และค้นหาระเบียนด้วย UUID ฝั่ง API
- ปรับหัวข้อและป้ายกำกับช่องค้นหาบุคลากรให้ชัดเจนและรองรับการเข้าถึง
- ปรับการเลือกบุคคลล่วงหน้าจากลิงก์ไปหน้าลงทะเบียนใบหน้า

## แก้ไขปัญหา
- แก้ API สถานที่และโซนที่เคยรับพารามิเตอร์ตัวเลขไม่ตรงกับสัญญา UUID
- ปรับชุดทดสอบการลงทะเบียนใบหน้าให้ใช้ API รายชื่อบุคคลแบบรวมตามพฤติกรรมจริง

## ข้อควรทราบก่อนอัปเดต
- รุ่นนี้เป็น Release Candidate และรวมการเปลี่ยนแปลงตั้งแต่ v1.1.0-rc16
- ก่อนอัปเดตให้สำรองฐานข้อมูลและไฟล์ระบบตามคู่มืออัปเดต ระบบจะหยุดให้บริการระหว่างติดตั้ง
- ฟีเจอร์บุคคลภายนอกและการเข้าเยี่ยมยังถูกควบคุมด้วย Feature Flag และปิดไว้ตามค่าเริ่มต้น
- การทำงานกับกล้องจริงและการยืนยันความแม่นยำในสภาพแวดล้อมของสถานที่ติดตั้งยังต้องทดสอบหน้างานก่อนใช้งานจริง
- หากหน้าเว็บยังแสดงชุดเดิม ให้กด Ctrl+F5 หลังอัปเดต
