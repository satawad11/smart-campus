## ฟีเจอร์ใหม่
- **ตั้งค่าการเชื่อมต่อระบบภายนอกจากหน้าเว็บ**: เมนู ผู้ดูแลระบบ → การเชื่อมต่อระบบภายนอก ตั้งค่าที่อยู่ API และกุญแจ API ของ RMS, เวลารอการตอบกลับ และเปิด/ปิดการซิงก์อัตโนมัติรายวันพร้อมเลือกเวลาได้ โดยไม่ต้องแก้ไฟล์บนเซิร์ฟเวอร์
- **ทดสอบการเชื่อมต่อ RMS**: กดปุ่มเดียวเพื่อตรวจว่าเซิร์ฟเวอร์ติดต่อ RMS ได้ ถ้าไม่สำเร็จระบบอธิบายสาเหตุเป็นภาษาไทย เช่น IP ของเซิร์ฟเวอร์ยังไม่ได้รับอนุญาต หรือกุญแจไม่มีสิทธิ์อ่านข้อมูล
- **สิทธิ์ใหม่ "จัดการการเชื่อมต่อระบบภายนอก"**: ให้เฉพาะผู้ดูแลระบบสูงสุด ผู้ใช้ที่ดูการตั้งค่าระบบได้จะเห็นหน้านี้แบบอ่านอย่างเดียว

## ปรับปรุง
- กุญแจ API ถูกเข้ารหัสก่อนเก็บ ไม่แสดงกลับบนหน้าเว็บ และไม่ถูกบันทึกลงบันทึกการตรวจสอบ หน้าจอแสดงเฉพาะรหัสกุญแจ (เช่น rmsk_9bcdb909_…)
- เมื่อเปลี่ยนที่อยู่ API ระบบให้กรอกกุญแจใหม่ทุกครั้ง เพื่อไม่ให้กุญแจเดิมถูกส่งไปยังเซิร์ฟเวอร์อื่น
- การแก้ไขและการทดสอบการเชื่อมต่อทุกครั้งถูกบันทึกในบันทึกการตรวจสอบ
- หน้าซิงก์ข้อมูลจาก RMS แสดงเวลาซิงก์อัตโนมัติเป็น "ทุกวัน HH:MM น." และบอกว่าตั้งค่าได้ที่เมนูใด

## แก้ไขปัญหา
- ไม่มีในรุ่นนี้

## ข้อควรทราบก่อนอัปเดต
- รุ่นนี้รวมทุกอย่างจาก v1.1.0-rc15 แล้ว เซิร์ฟเวอร์ที่ยังเป็นรุ่นเก่ากว่าอัปเดตมารุ่นนี้ได้เลย ถ้ายังไม่ได้ทำขั้นตอนใน "ข้อควรทราบก่อนอัปเดต" ของรุ่นก่อนหน้า ให้ทำด้วย
- รุ่นนี้เพิ่มตารางใหม่ในฐานข้อมูล 1 ตาราง และสิทธิ์ใหม่ 1 รายการ (ระบบเพิ่มให้อัตโนมัติ ไม่แก้ข้อมูลเดิม) ระบบปิดให้บริการระหว่างอัปเดตประมาณ 5 ถึง 10 นาที และสำรองข้อมูลให้อัตโนมัติก่อนเริ่ม
- ค่า RMS ที่ตั้งไว้ในไฟล์ .env ยังใช้งานได้ตามเดิมจนกว่าจะบันทึกค่าใหม่จากหน้าเว็บ
- ก่อนกดทดสอบการเชื่อมต่อ ให้ผู้ดูแล RMS ใส่ IP ของเซิร์ฟเวอร์นี้ในช่อง "IP ที่อนุญาต" ของกุญแจ (กรอกกุญแจผิด 10 ครั้งใน 15 นาที RMS จะระงับการเรียก 15 นาที)
- กุญแจถูกเข้ารหัสด้วย APP_KEY ของเซิร์ฟเวอร์ ถ้าย้ายเซิร์ฟเวอร์หรือเปลี่ยน APP_KEY ต้องกรอกกุญแจใหม่
- หลังอัปเดต ถ้าหน้าเว็บยังแสดงแบบเดิม ให้กด Ctrl+F5 เพื่อโหลดหน้าใหม่
