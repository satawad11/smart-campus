## ฟีเจอร์ใหม่
- **จดจำใบหน้าด้วยโมเดลจริง**: ระบบมีโมเดลตรวจจับใบหน้า (YuNet) โมเดลจดจำใบหน้า (SFace) และโมเดลตรวจภาพปลอม (MiniFASNet) ติดมากับชุดติดตั้ง ใช้แทนผลจำลองเดิม การติดตั้งใหม่ใช้โมเดลจริงเป็นค่าเริ่มต้น เซิร์ฟเวอร์ที่ติดตั้งไว้แล้วต้องเปิดใช้เอง ดูหัวข้อ "ข้อควรทราบก่อนอัปเดต"
- **ตรวจภาพปลอม**: ถ้ามีคนยื่นรูปถ่ายหรือหน้าจอโทรศัพท์ให้กล้อง ระบบจะไม่ยืนยันตัวตนจากภาพนั้น ความแม่นยำกับกล้องจริงของวิทยาลัยยังไม่ได้วัด

## ปรับปรุง
- **แดชบอร์ด**: เพิ่มการ์ด "รอตรวจสอบ" และ "ไม่ทราบตัวตน" แสดงจำนวนคนที่จดจำได้โดยไม่นับซ้ำ การ์ดหน่วยประมวลผลเปลี่ยนเป็นสีส้มเมื่อมีหน่วยออฟไลน์ และกราฟรายชั่วโมงแสดงข้อความเมื่อวันนี้ยังไม่มีการเข้า-ออก

## แก้ไขปัญหา
- แดชบอร์ดแสดงตัวเลข กราฟ และตารางไม่ครบหรือว่างเปล่า ตอนนี้แสดงครบแล้ว
- ภาพจากกล้องถูกส่งเข้าโมเดลโดยสลับสีแดงกับสีน้ำเงิน ทำให้จดจำได้แม่นน้อยลง
- เมื่อมีหลายคนอยู่ในภาพเดียวกัน ระบบเคยจดจำทุกคนจากใบหน้าแรกในภาพ ตอนนี้แต่ละคนใช้ใบหน้าของตัวเองแล้ว

## ข้อควรทราบก่อนอัปเดต
- ระบบปิดให้บริการระหว่างอัปเดตประมาณ 5 ถึง 10 นาที และสำรองข้อมูลให้อัตโนมัติก่อนเริ่ม
- การอัปเดตไม่เปลี่ยนโหมดของเซิร์ฟเวอร์เดิม ถ้าต้องการเปิดใช้โมเดลจริง ให้รัน 3 คำสั่งนี้บนเซิร์ฟเวอร์หลังอัปเดต:

```
sudo sed -i 's/^AI_MODE=.*/AI_MODE=onnx/' /opt/smart-campus/campus.env
sudo smart-campus start
sudo smart-campus artisan face:model-activate yunet-sface 2021dec
```

- ใบหน้าที่ลงทะเบียนไว้ในโหมดจำลองใช้กับโมเดลจริงไม่ได้ ต้องลงทะเบียนใบหน้าใหม่ทั้งหมด
- ค่าเกณฑ์การจดจำใบหน้ายังเป็นค่าเริ่มต้น ต้องทดสอบกับอาสาสมัครที่ยินยอมก่อน แล้วผู้บริหารจึงอนุมัติค่าใหม่ (FACE-021)
- ลงทะเบียนใบหน้าได้เฉพาะผู้ที่ให้ความยินยอมเป็นลายลักษณ์อักษรแล้ว (ข้อมูลชีวภาพ ตาม PDPA มาตรา 26) ผู้เยาว์ต้องได้รับความยินยอมจากผู้ปกครอง
- ผู้เผยแพร่โมเดลไม่ได้ระบุว่าใช้ข้อมูลอะไรฝึกโมเดล รุ่นนี้จึงใช้ได้เฉพาะโครงการนำร่องภายในวิทยาลัย ห้ามนำไปขายหรือแจกจ่ายต่อ (ACR-AI-01)
- หน่วยประมวลผล AI (Raspberry Pi) ต้องอัปเดตเป็นรุ่นนี้ด้วย และตั้งค่า `AI_MODE=onnx` จึงจะจดจำใบหน้าจากกล้องได้จริง
