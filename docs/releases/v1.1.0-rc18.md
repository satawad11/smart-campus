## ฟีเจอร์ใหม่
- แจ้งเตือนแบบป๊อปอัพสำหรับเหตุการณ์ที่ต้องตรวจสอบ (REVIEW) บนหน้าจอที่เปิดระบบอยู่
- แจ้งเตือนเมื่อพบใบหน้าที่จับคู่ได้แต่เป็นบุคคลประเภทอื่น หรือมีสถานะไม่ใช้งาน รวมถึงนักเรียนพ้นสภาพและบุคลากรที่ไม่ได้ปฏิบัติงาน

## ปรับปรุง
- ปรับการเปิด RTSP ของ AI Node ให้ใช้ TCP เป็นค่าเริ่มต้น สอดคล้องกับการดูภาพตัวอย่างกล้อง และยัง override ได้จาก environment
- ปรับ readiness check ให้ตรวจ OpenCV ซึ่งเป็น runtime ที่ provider ใช้งานจริง

## แก้ไขปัญหา
- สถานะ INACTIVE/ARCHIVED ของทะเบียนบุคคลจะมีผลเหนือสถานะ ACTIVE ในโปรไฟล์นักเรียนหรือบุคลากร
- ปิดกฎ ALLOW เดิมสำหรับผู้เยี่ยมชมที่กำลังเข้าเยี่ยมและผู้ปกครองที่มีนักเรียน ACTIVE; เหตุการณ์จากบุคคลเหล่านี้จะถูกส่งให้ผู้ดูแลตรวจสอบ

## ข้อควรทราบก่อนอัปเดต
- รุ่นนี้เป็น Release Candidate สำหรับทดสอบในสถานที่ติดตั้ง โปรดสำรองข้อมูลและตรวจผล GitHub Actions ก่อนอัปเดต
- การตรวจจับและจับคู่ใบหน้าจากกล้องจริงยังต้องทดสอบหน้างาน กล้องที่ยังส่งภาพไม่พบใบหน้าอาจยังต้องตรวจตำแหน่ง/สตรีม/การตั้งค่ากล้องเพิ่มเติม
- เซิร์ฟเวอร์หลักและ AI Node เป็นชุดอัปเดตแยกกัน ให้อัปเดตเซิร์ฟเวอร์ก่อน แล้วจึงอัปเดต AI Node ตามคู่มือ
