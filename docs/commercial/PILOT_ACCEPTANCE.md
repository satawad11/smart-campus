# Commercial Pilot Acceptance

The V1 pilot acceptance pack is [PILOT-011](../pilot/PILOT-011-FINAL-PILOT-ACCEPTANCE.md) with evidence documents
PILOT-001..010. This page adds the commercial criteria; it doesn't replace them.

| # | Criterion | Evidence required | Status |
|---|---|---|---|
| 1 | Approved release deployed by the installation guide | deployment record, preflight PASS | BLOCKED (no host; PILOT-000B approval) |
| 2 | Licence installed and enforced (`enforce`) | `license:status` output; refused over-limit camera in a test | not started |
| 3 | 7- and 14-day stability | PILOT-006/010 uptime, alert log | AWAITING elapsed time |
| 4 | Recognition quality within FACE-021 criteria | PILOT-007 metrics on approved data | BLOCKED (B5) |
| 5 | Backup + restore on the pilot host | PILOT-003/009 records | BLOCKED |
| 6 | Operators trained, walkthrough done | PILOT-004 sign-off | AWAITING humans |
| 7 | PDPA items for the pilot (notice, legal basis, DPA) | signed documents | AWAITING legal |
| 8 | Incident handling exercised | PILOT-008 | AWAITING pilot |
| 9 | Installation time and support effort measured | timesheet / ticket log | not started |
| 10 | Institution and vendor sign acceptance | signed PILOT-011 | AWAITING |

No item may be marked done from rehearsal or workstation evidence alone.
