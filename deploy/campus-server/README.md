# AI Smart Campus — ชุดติดตั้งเซิร์ฟเวอร์หลัก

ชุดนี้มีทุกอย่างที่ต้องใช้ ติดตั้งได้โดยไม่ต้องต่ออินเทอร์เน็ตและไม่ต้องมี source code

## เครื่องที่ต้องใช้

- Linux 64 บิต (แนะนำ Ubuntu Server 22.04 หรือ 24.04) และสิทธิ์ root
- RAM อย่างน้อย 8 GB และพื้นที่ว่างอย่างน้อย 40 GB
- พอร์ต 80 และ 443 ว่าง
- ถ้ายังไม่มี Docker ตัวติดตั้งจะเสนอติดตั้งให้จากคลังแพ็กเกจของ Ubuntu

## ติดตั้ง

```bash
tar -xzf campus-server-kit-<version>-amd64.tar.gz
cd campus-server-kit-<version>-amd64
sudo ./install.sh
```

ตัวติดตั้งจะถาม 4 ข้อ และทุกข้อกด Enter เพื่อใช้ค่าเริ่มต้นได้:

1. ชื่อสถานศึกษา
2. ชื่อเครื่องหรือ IP ที่ผู้ใช้จะเปิดเว็บ
3. ชื่อผู้ใช้ของผู้ดูแลระบบคนแรก
4. โฟลเดอร์เก็บสำรองข้อมูล

จากนั้นตัวติดตั้งจะทำต่อให้เอง:

- สร้างรหัสผ่านทุกตัวแบบสุ่ม
- สร้างฐานข้อมูล ที่เก็บไฟล์ และใบรับรอง HTTPS
- สร้างผู้ดูแลระบบคนแรก
- สำรองข้อมูลครั้งแรก
- ตรวจสุขภาพระบบ

เมื่อเสร็จ ตัวติดตั้งจะแสดงลิงก์เว็บและรหัสผ่านครั้งแรก รหัสนี้แสดงเพียงครั้งเดียว

ไม่ต้องการให้ถามคำถาม: `sudo SC_HOST=campus.example.ac.th ./install.sh --yes`

## หลังติดตั้ง

1. **คัดลอก `/opt/smart-campus/campus.env` ไปเก็บไว้นอกเครื่อง** ไฟล์นี้มีรหัสผ่านทั้งหมดและกุญแจถอดรหัสไฟล์สำรอง ถ้าไฟล์นี้หายจะกู้ข้อมูลจากไฟล์สำรองไม่ได้
2. **ใบรับรอง HTTPS** ตัวติดตั้งสร้างใบรับรองภายในให้ จึงต้องติดตั้งไฟล์ `/opt/smart-campus/infrastructure/pilot/ca/ca.crt` ในเครื่องผู้ใช้และใน AI Node ถ้าใช้ใบรับรองของสถานศึกษาเอง ให้รัน `sudo smart-campus tls import <fullchain.pem> <privkey.pem>` แทน
3. **License** เข้าเว็บแล้วอัปโหลดไฟล์ license ที่ได้รับจากผู้ขาย
4. **การจดจำใบหน้า** `AI_MODE=mock` แปลว่ายังไม่จดจำใบหน้าจริง จนกว่าจะอนุมัติโมเดล (PILOT-000 B5)

## ดูแลระบบ

```bash
sudo smart-campus status       # สถานะ
sudo smart-campus logs backend # log
sudo smart-campus backup       # สำรองข้อมูลทันที
sudo smart-campus preflight    # ตรวจความพร้อมใช้งานจริง
```

## อัปเดต

### ผ่าน GitHub (ผู้ดูแลกดเอง)

ตั้งค่าครั้งแรก (ทำครั้งเดียว):

```bash
sudo smart-campus update-setup
```

ระบบจะถามชื่อ repository และ token ของ GitHub ให้สร้าง token แบบ fine-grained ที่อ่าน repository นี้ได้อย่างเดียว
(Contents: Read-only) token จะถูกเก็บใน `/opt/smart-campus/update.env` สิทธิ์ 600 และไม่แสดงบนหน้าจอ

ทุกครั้งที่มีรุ่นใหม่:

```bash
sudo smart-campus update-check        # ดูรุ่นที่มีและรุ่นที่ติดตั้งอยู่
sudo smart-campus update v1.2.0       # อัปเดตเป็นรุ่นที่ระบุ (ไม่ระบุ = รุ่นล่าสุดที่ไม่ใช่รุ่นทดสอบ)
```

คำสั่ง `update` จะแสดงบันทึกการเปลี่ยนแปลงของรุ่นนั้นและถามยืนยันก่อน จากนั้นดาวน์โหลดชุดติดตั้งจาก GitHub Release
ตรวจ SHA-256 (ถ้าไม่ตรงจะลบไฟล์ทิ้งและไม่ติดตั้ง) แล้วรันตัวติดตั้งของรุ่นนั้นตามขั้นตอนด้านล่าง

ถ้ารุ่นใหม่มีปัญหา ย้อนกลับไปรุ่นก่อนหน้าได้ด้วย `sudo smart-campus rollback` คำสั่งนี้ย้อนเฉพาะโปรแกรม ไม่ย้อนฐานข้อมูล
ถ้ารุ่นใหม่เปลี่ยนโครงสร้างฐานข้อมูลจนรุ่นเดิมใช้ไม่ได้ ให้กู้จากไฟล์สำรองที่ทำก่อนอัปเดต
ดูประวัติการอัปเดต: `sudo smart-campus version`

### แบบไม่มีอินเทอร์เน็ต

แตกชุดติดตั้งรุ่นใหม่ แล้วรัน `sudo ./install.sh` ในโฟลเดอร์นั้น ตัวติดตั้งจะทำตามลำดับนี้:

1. สำรองข้อมูลและตรวจไฟล์สำรองก่อน
2. เก็บ image รุ่นเดิมไว้สำหรับย้อนกลับ
3. อัปเดตฐานข้อมูล
4. เริ่มระบบใหม่

ค่าใน `campus.env` เดิมจะไม่ถูกเปลี่ยน ตัวติดตั้งไม่ลบข้อมูลใด ๆ
